# Folder Notes:
This folder includes the main code of Fast-TDA (ellipse fitting) and the data from the PCB shock test.

## What this folder contains
1- data.csv: This CSV file contains the excitation as the  acceleration signals from the PCB (Output).

2- Fast_TDA.m: This m file is the main fast TDA algorithm ( ellipse fitting ).

3-myVideo.mp4: This video shows the evolution of ellipse fitting during windowing, showing how the ellipse's shape and size change over TDA processing.
